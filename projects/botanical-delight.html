Botanical Delight

A Minecraft mod that adds farming content: a tomato crop, a watering can, and everything around them.

The product video: planting, growing and harvesting tomatoes in game.

Overview

This was the ambition project — half a day a week for half a year, in a group of three, working in sprints. We chose to build a Minecraft mod, which meant learning Java and a modding framework instead of using an engine we already knew.

A mod is not a game you start from nothing. You are adding to something that already works, so your code has to fit rules someone else wrote. That turned out to be the most useful part of the whole project.

What is in the mod

  • A tomato crop — TomatoCropBlock, with growth stages and its own textures per stage
  • A watering can — a filled and an empty version, as two item classes
  • Blocks and items registries — ModBlocks and ModItems
  • Loot tables — so breaking a crop drops the right thing
  • Recipes — so you can actually craft the new items
  • Block states and models — generated with data providers instead of written by hand

Technologies used

  • Java
  • Minecraft Forge (1.21)
  • Gradle for building and running the test client
  • Data generation for models, tags, recipes and loot tables

What I learned

  • Java, coming from C#: close enough to read, different enough to catch you out
  • Writing code that plugs into an existing system and follows its rules
  • Letting data generators do repetitive work instead of writing JSON by hand
  • Working in sprints with a group over a long period, where you have to pick up where you left off weeks later
