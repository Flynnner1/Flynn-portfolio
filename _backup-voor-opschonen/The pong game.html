First project

Pong: learning the fundamentals

Where I worked out how a game actually runs, one frame at a time.

Overview

This was my first step into game development: a recreation of the classic game of Pong. The goal was never to build something complex — it was to understand the fundamentals that make any game work, especially the game loop.

What I learned

  • The game loop — how a game runs the same cycle over and over to update state and render the result, and why Update() and FixedUpdate() are separate.
  • Player input — listening for keypresses and turning them into paddle movement.
  • Physics and collision — moving the ball, detecting hits against paddles and walls, and making the bounce feel right.
  • Scoring and game state — tracking points and resetting the ball after each one.

Technologies used

  • Unity
  • C#
