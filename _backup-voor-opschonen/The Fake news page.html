Web project

GIN — Gaming Inaccurate News

A parody of IGN, built to learn how a real news layout is put together.

Overview

GIN (Gaming Inaccurate News) is a parody site modelled closely on the gaming media outlet IGN. Having a real site to work from made this a genuinely fun project — instead of inventing a layout, I had to look carefully at an existing one and work out how it was built.

Project goals

  • Show what I could do with HTML
  • Practise the basics of building a website
  • Reverse-engineer IGN's layout and rebuild it

How GIN works

GIN carries completely fake but plausible-looking articles — Minecraft 2 being released, that sort of thing. The point is to entertain the visitor while demonstrating page layout, CSS styling and content structure.

Technologies used

  • HTML for structure
  • CSS for responsive styling

What I learned

  • Building a single-page parody site
  • Matching an existing design closely with CSS
