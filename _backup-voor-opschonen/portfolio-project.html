The site you're reading right now, built by hand in HTML and CSS.

Overview

This project documents my web development work at Sint-Lucas. It's a responsive site with a page of its own for every project, written without a framework so that every layout decision in it is one I had to make myself.

Features

  • Responsive layout that works from phone to desktop
  • A single shared stylesheet, so a change to the design lands on every page at once
  • Dark green-on-black colour scheme built from CSS custom properties
  • A separate detail page for each project
  • Skills overview and a contact form

Technologies used

  • HTML5
  • CSS3 (Flexbox & Grid, custom properties)
  • JavaScript for the scroll-spy navigation and the contact form

What I learned

  • Building and styling responsive layouts
  • Organising content so it's clear and accessible
  • Linking multiple HTML pages into one coherent site
  • Using colour and typography deliberately instead of decoratively
