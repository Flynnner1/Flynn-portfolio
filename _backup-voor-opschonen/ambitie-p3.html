Published game

Arcana Rift

A top-down action game built in Unity and C#, with every sprite drawn by hand in pixel art.

Overview

This project highlights my game development journey at Sint-Lucas. I built it on my own for the school showcase, which meant designing and implementing every system in it — from the inventory to the way enemies decide where to spawn.

Features

  • A working inventory — drag, drop, stack and hotbar
  • A quest giver — randomised objectives from an NPC
  • 25 enemy variations — five families, five rarities each
  • Five spells and attacks — each with its own feel
  • A levelling system — XP, levels and buyable upgrades
  • An HP system — damage, healing and defeat
  • Zone-based spawning — weighted chances per biome
  • A kill counter — saved between sessions

Technologies used

  • Unity
  • C#
  • Pixel art (hand-drawn)

What I learned

  • Building an inventory from scratch
  • Creating items and getting them into that inventory
  • Making items draggable between slots
  • Wiring a hotbar to the number keys
